\# AI Usage



AI tools were used as development assistance during the CivicPulse project.



\## Areas where AI assistance was used



\- Understanding and troubleshooting frontend React, TypeScript, Vitest, and Testing Library setup.

\- Developing and refining frontend component tests.

\- Troubleshooting ESLint configuration and React Hooks linting issues.

\- Understanding and troubleshooting backend pytest and coverage configuration.

\- Reviewing CI workflow structure and identifying configuration issues.

\- Troubleshooting Git and GitHub Actions errors.

\- Reviewing Dockerfiles and configuration files for potential issues.

\- Generating explanations and suggestions for implementation approaches.



\## Human contribution



The team remained responsible for the final implementation, integration, testing, Git commits, and decisions made in the project. AI-generated suggestions were reviewed and adapted before being incorporated into the repository.



\## Verification



Code suggested by AI was tested locally where applicable. CI results were also used to verify that the implemented changes passed the project's automated checks.



AI assistance was treated as a development aid rather than as a replacement for testing, review, or engineering decisions.
